Set up GTM Alpha in your AI assistant

GTM Alpha has three tools:

  • Free EPIC audit (in your browser and in Claude): your EPIC scores and the motion to lead with.
  • EPIC scores (in Claude): your EPIC scores with the rule behind each.
  • GTM Roadmap (in Claude): a 30, 60 or 90 day plan for one motion.

Set it up in Claude

Add GTM Alpha as a custom connector in four steps. Nothing to install.

Claude on the web, desktop or mobile (no install):

  1. Open Customize, then Connectors, select +, then Add custom connector
  2. Name it GTM Alpha
  3. MCP server URL: https://gtmalpha.gtmhelix.com/mcp
  4. Choose no sign-in, then Add

Or run it locally with the npm package:

In Claude Code, one command adds it:

claude mcp add gtm-alpha -- npx -y @shashwatgtmalpha/gtm-alpha-mcp-server

In Claude Desktop, add it to the configuration file.

Configuration File Location:

Windows: %APPDATA%\Claude\claude_desktop_config.json
macOS: ~/Library/Application Support/Claude/claude_desktop_config.json

Setup Instructions:

  1. Open the configuration file in your text editor
  2. Add the GTM Alpha server configuration
  3. Save the file and restart Claude Desktop
  4. Test with: "Analyze my GTM strategy using EPIC framework"
MCP Registry npm Package
claude_desktop_config.json
{ "mcpServers": { "gtm-alpha": { "command": "npx", "args": ["-y", "@shashwatgtmalpha/gtm-alpha-mcp-server"] } } }

Set it up in ChatGPT

ChatGPT can use remote MCP servers as custom connectors on plans that allow developer mode. In ChatGPT's settings, open the connectors (apps) section, turn on developer mode if your plan requires it, create a connector with the URL https://gtmalpha.gtmhelix.com/mcp and no authentication, then enable it in a chat. Menu names change between ChatGPT releases; OpenAI's help centre has the current path.

How the connector works

  • Address: https://gtmalpha.gtmhelix.com/mcp (the older address /mcp-sse also works)
  • JSON-RPC 2.0 over HTTP POST (Streamable HTTP transport, JSON responses)
  • MCP protocol versions: 2025-06-18, 2025-03-26, 2024-11-05
  • Server version: 1.3.3
  • Tool annotations for safety: all three tools are read-only
  • Tool names: gtm_consultation (Free EPIC audit (in your browser and in Claude)), epic_audit (EPIC scores (in Claude)), generate_roadmap (GTM Roadmap (in Claude))

Call a tool

API request example (curl)
curl -X POST https://gtmalpha.gtmhelix.com/mcp \ -H "Content-Type: application/json" \ -d '{ "jsonrpc": "2.0", "id": 1, "method": "tools/call", "params": { "name": "gtm_consultation", "arguments": { "gtm_challenge": "How to enter enterprise market?" } } }'

Before you connect GTM Alpha

  • Claude plan: any. Custom connectors work on Claude's Free, Pro, Max, Team and Enterprise plans; the Free plan allows one custom connector.
  • Team or Enterprise: only an Owner can add a custom connector, under Organization settings, Connectors, Add, Custom, Web. Members then turn it on under Customize, Connectors.
  • Accounts and keys: none. There is no sign-in and no API key.
  • Local use: the npm package needs Node.js 18 or later.

Who is GTM Alpha not ideal for?

GTM Alpha is a read-only strategy tool for B2B teams choosing which go-to-market motion to lead with. It is not the right fit for:

  • Teams that want an AI-written strategy: the EPIC scores follow fixed rules from the documented rubric, and no AI model writes them.
  • Companies that cannot share basic numbers: without contract value, deal cycle, net revenue retention and target account count, the result is marked preliminary.
  • Anyone who needs live market data: GTM Alpha looks nothing up and works only from what you enter.
  • Anyone who needs a tool that writes to a CRM or other systems: all three tools are read-only and return analysis only.
